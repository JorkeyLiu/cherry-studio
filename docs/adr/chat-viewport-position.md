## 1. 背景与问题（Background and Problem）

路由切换时的滚动恢复长期存在三类漂移：把发出侧（outgoing）滚动位置写成目标路由的视口；把程序化中间几何（过渡帧、边缘停靠、未对齐的首绘）提交为稳定快照；在新路由增量取数尚未完成时，让旧展示 DOM 以新路由身份写入位置。若不锁定每路由视口的归属、恢复意图的生命周期与稳定完成的判定条件，同一份“看起来在正确位置”的 UI 可能对应三种不同的语义：真实稳定恢复、中间过渡、错误路由的残留。

同路由在位交互引入第二类漂移：改变消息内容/布局的控件（展开/折叠、编辑进出、分支操作、重发/重新生成、回答组选择等）触发布局变化后，视口跳到无关位置——或以原始 `scrollTop` 硬保持而让被点击的交互区滑出可视帧，或回跳到任意旧行顶。流式生成引入第三类漂移：被动内容增长劫持正在阅读的用户视口，或阅读中的点击被误读为“回到跟随”。

本文档以 VIEWPORT-1…VIEWPORT-12 锁定路由维度模型（**每路由拥有其上次稳定视口；目标路由只按自身快照或自身确定性默认定位；中间几何永不成为稳定位置；不可见过渡失败时 fail-visible**），以 VIEWPORT-13…VIEWPORT-16 锁定已验证的语义内核扩展（**同路由在位交互保持被点击/聚焦的稳定视觉交互区；共享控制器仲裁而非按钮级补偿；流式下阅读意图优先于被动跟随；位置意图按显式导航/真实用户滚动 > 在位控件与阅读意图 > 被动布局与跟随的优先级裁决**）。`docs/architecture/architecture.md` 描述实现位置，演进计划文档仅引用本文档。

**范围澄清（不新增决策锁）**：既有路由切换约束是“路由独占、目标自给”（目标输入只来自目标自身，§6/§9 VIEWPORT-5）；同路由交互几何（§7）与分隔线显式延续意图（§6/§9）是两类已明确的独立语义，不是对普通路由切换的放宽。普通路由切换永不复用发出侧滚动值；不得把“同路由保持交互区”或“分隔线显式延续保持当前视口”静默推广为“普通切换可复用发出侧位置”。

## 2. 术语（Terminology）

| 术语 | 标识符 | 定义 |
|---|---|---|
| 路由 | route | 一次权威读写所寻址的逻辑 topic 内分支（main 或某分支）。构成与权限语义由 [Topic Branches](./topic-branches.md)（BRANCH-2/11）唯一治理；本文档只定义路由的视口归属。路由不同于页面：topic/分支切换是路由切换，Chat/Settings 切换是页面切换 |
| 页面 | page | 主要页面之间的激活切换（例如 Chat→Settings→Chat）。页面切换是活动页变更，不是浏览会话的自动销毁；同一聊天路由的稳定视口会话跨页面停用存续，返回时回到同一路由的稳定浏览位置（类浏览器标签行为）；不新增标签页 UI，不承诺重启续读；一致的语义期望，实现范围为聊天会话 secondary 往返 |
| 选中路由 | selected route | 选择器/导航状态当前指向的路由（用户意图的去向） |
| 展示路由 | displayed route | 当前已提交渲染的投影所归属的路由（DOM 内容的来源身份） |
| 路由本地稳定视口 | route-local stable viewport | 某路由上次验证有效的视口位置：稳定消息身份 + 行内偏移/底部语义。它是该路由的本地属性，与用户是否输入/滚动无关。路由维度是聊天视口定位的子集 |
| 视口快照 | viewport snapshot | 路由本地稳定视口的已提交记录（按路由键索引）。快照是可丢弃的渲染投影，不是聊天权威 |
| 恢复意图 | restore intent | 指向目标路由的待完成恢复（目标稳定身份 + 期望偏移）。意图在稳定完成或终态回退前一直存活；分普通恢复意图与分隔线显式延续意图两类（§4–§6），后者优先 |
| 普通恢复意图 | normal resume intent | 默认隐式意图：目标只按自身快照或自身确定性默认定位（VIEWPORT-5）。普通路由切换与 secondary 页面往返均属此类 |
| 分隔线显式延续意图 | divider explicit continuation intent | 从分支分隔线发起的独有显式浏览意图：表示从当前视口开始浏览目标分支后缀。定位期间保持当前视口，不被目标历史快照覆盖；只有稳定后的结果才成为该路由后续会话位置；不改变分支权限与上下文锚点 |
| 路由稳定视口会话 | route stable viewport session | 每路由长期存续的隐式浏览会话：持有该路由上次稳定视口。普通切换与 secondary 页面往返均从各自上次稳定阅读位置继续；页面停用与重连不断开该会话；不新增标签 UI，不承诺重启续读。不承诺所有 secondary 页面均保持挂载：语义期望一致，实现范围为聊天会话 secondary 往返 |
| 保留投影 | retained projection | 页面停用期间得以保留的已提交展示投影（若实现保留）。重激活时可验证+对齐的候选，不自动成为稳定视口；其验证仅属展示正确性，不证明投影完备性或聊天新鲜度（PROJ 治理域不变），投影永不成为权威 |
| 视口资源 | viewport resources | 可分离/重连的展示与测量能力（已提交投影的挂载与度量占位）。停用时断开、重激活时重连；断开不等于会话销毁 |
| 激活/恢复事务 | activation/restore transaction | 每次进入目标路由（含页面重激活）时创建的短寿命守卫过程：以目标快照或目标默认（或显式分隔线意图）为输入，走 §5 阶段到稳定或终态回退；上一事务的迟到完成永不复用于新代际。重激活事务允许先验证+对齐已有的有效保留投影（无需无条件取数或重建）；保留投影不能安全覆盖所请求的稳定身份时，走既有的自身目标快照/默认恢复 |
| 恢复所有权 | restore ownership | 当前过渡由哪一次路由切换拥有。所有权决定谁可以分页、谁可以提交、谁可以释放；过期所有者的一切完成均无效 |
| 定位中 / 已放置 / 搜索中 / 已对齐 / 稳定 / 终态回退 | positioning / placed / searching / aligned / stable / terminal fallback | 恢复生命周期的互斥阶段（§5）。首绘已放置不等于稳定 |
| 边缘停靠 | edge parking | `searching` 阶段在可滚动边缘的临时停靠（中间几何），用于使恢复拥有的分页得以推进 |
| 分隔线 | divider | 上下文窗口起始边界的 UI 表现（稳定身份）。分隔线恢复是视口恢复的一类目标形态 |
| 共享消息回退 | shared-message fallback | 当所请求的稳定身份缺席时，显式声明的同代有效替代身份（目标路由内驻留且被覆盖的消息）。隐式就近替代不是合法回退 |
| 恢复拥有的分页 | restore-owned pagination | 由当前恢复所有者驱动的窗口扩展（按状态/驻留驱动，不由滚动事件驱动） |
| 路由代际 | route epoch | 区分连续路由切换的单调代际。展示提交与揭示必须与目标代际一致 |
| 发出侧来源 | outgoing provenance | 离开路由时保存的快照所标注的来源路由身份。保存只允许展示路由来源 |
| 同路由在位交互 | same-route in-place interaction | 同一路由内改变消息内容/布局的控件交互（展开/折叠、编辑进出、分支与回答组操作、重发/重新生成等，含既有标签页同类交互）。它不切换路由、不产生恢复意图，其几何语义由 VIEWPORT-13/14 治理，不走 §5 恢复生命周期 |
| 稳定视觉交互区 | stable visual interaction region | 在位交互中被点击/聚焦的控件所属的稳定视觉区域（行身份 + 区内位置语义）。连续性的锚定对象是它，不是原始滚动值、不是任意旧行顶 |
| 结构对应区 | structural correspondence | 控件被替换时的跨形态对应关系（例如消息底部操作区与编辑器操作区的对应）。只有结构对应的区域可继承连续性；无有效对应即无连续性目标 |
| 布局补偿 | layout compensation | 为抵消内容/布局变化对视口的被动位移而进行的程序化位置调整。它本身永不写入快照，只维持视觉连续；快照只由安静后验证的稳定位置写入 |
| 流式跟随 / 流式阅读 | streaming follow / streaming reading | 流式生成期间的两种视口含义：跟随（视口随新内容保持底部语义）与阅读（视口保持在用户选定的行锚点，不被被动增长劫持）。两者由行锚 vs 底部跟随的含义区分，不由新的持久化暂停模式表达 |
| 真实物理底部 | actual physical bottom | 用户视口真实到达可滚动末端的状态。只有它可恢复跟随；快照邻近（`isAtBottom`  vicinity 语义）不是它 |
| 共享视口控制器/保持器 | shared viewport controller/keeper | 同一路由内仲裁全部在位交互与布局补偿的 renderer 本地单一控制器。按钮级补偿器不得各自为政 |

## 3. 决策表（Decision Table）

| # | 决策 | 状态 |
|---|---|---|
| **VIEWPORT-1** | **每路由拥有其上次稳定视口**。位置有效性独立于用户是否输入或滚动：无滚动不等于无位置，无输入的路由仍可持有有效快照 | **Locked** |
| **VIEWPORT-2** | **选中路由、展示路由、路由本地稳定视口三者严格区分**。离开保存只允许展示路由来源（displayed-route provenance），永不以选中路由身份保存展示内容 | **Locked** |
| **VIEWPORT-3** | **成功的程序化恢复是合法的稳定视口**；程序化中间几何不是。是否稳定取决于是否走完稳定完成判定（§6），不取决于触发方式是用户滚动还是程序化定位 | **Locked** |
| **VIEWPORT-4** | **进入路由增量取数期间，旧展示 DOM 不得以进入路由身份写入位置**。来源身份与写入身份必须一致；身份不一致的写入一律丢弃 | **Locked** |
| **VIEWPORT-5** | **有快照的目标按稳定消息身份 + 行内偏移/底部语义恢复**；同路由原始滚动值只允许作为本地回退。**无快照的目标使用确定性目标路由默认**；永不使用发出侧滚动值 | **Locked** |
| **VIEWPORT-6** | **目标投影从提交到有效首绘定位完成前保持隐藏但可测量；揭示按路由/代际守卫；失败 fail-visible**。永不展示错位内容冒充恢复成功，永不静默停留在隐藏状态 | **Locked** |
| **VIEWPORT-7** | **生命周期语义互斥且不可跳级**：`positioning` → `placed` →（`searching`）→ `aligned` → `stable`，另有 `terminal fallback` 终态。首绘已放置不自动成为稳定 | **Locked** |
| **VIEWPORT-8** | **`searching` 边缘停靠是中间几何**。它可以使恢复拥有的分页得以推进，但**不能**提交稳定快照、清除恢复意图、释放恢复所有权 | **Locked** |
| **VIEWPORT-9** | **分隔线恢复的稳定完成要求四者合取**：所请求的稳定身份分隔线、或显式合法的共享消息回退已驻留且被覆盖；恢复拥有的分页已完成；目标已对齐；布局已安静。分页由状态/驻留驱动，不由滚动事件驱动；意图与偏移在窗口增长中存活 | **Locked** |
| **VIEWPORT-10** | **终态回退释放并可见失败，不提交虚假中间几何；保留已有的合法目标快照**（如有）。回退永不伪造一次稳定完成 | **Locked** |
| **VIEWPORT-11** | **超前/路由切换/删除/卸载使过期完成失效；释放恰好一次**。过期所有者的迟到完成（稳定提交、揭示、释放）一律丢弃，不得复用新代际 | **Locked** |
| **VIEWPORT-12** | **回归契约冻结**（§12）：无滚动顶部分隔线往返、普通用户滚动后无滚动往返、无快照目标默认、快速超前、分隔线缺席锚点分页/偏移、原子可见性与失败路径。任一契约回归即判定违反本文档 | **Locked** |
| **VIEWPORT-13** | **同路由在位控件交互以视觉基线为准向变化方向平衡高度差**。改变消息内容/布局的控件必须保持符合心理预期的视觉基线处的稳定视觉交互区，而非原始滚动值、固定 `scrollTop` 数字或任意旧行顶；视觉基线通常即交互区域本身，若交互区域被替换且几何本身变化则取变化区域下方/上方未变化的结构边界，不人为压缩组件以维持错误点。平衡方向由变化侧决定：变化在基线上方则向上平衡，变化在基线下方则向下平衡（模型标签上方回答变化向上、分支分割线下方内容变化向下、编辑消息以上方变化取下方不变边界为基线均为该方向规则的语义示例，其中分支示例不构成当前分支实现已通过的声称）。自然变化的上方/下方内容按布局变化，不要求所有页面像素不变。首见帧与每一可见帧均须连续，仅终态纠正不够；用户主动镜头移动优先，真实物理不可达边界诚实钳制（与高度最小/最大约束不同）；普通控件激活不是显式滚动导航，原生焦点不得暗中重定位；已移除且无有效对应的区域 fail-closed（不猜测替代、不谎报稳定成功） | **Locked** |
| **VIEWPORT-14** | **共享 renderer 本地控制器/保持器唯一仲裁**。同一路由的全部在位交互与布局补偿由单一共享视口仲裁，不允许每组件独立滚动或独立补偿，不设按钮级补偿器；组件保留正常样式留白与按钮比例，视觉基线选择不靠强制尺寸一致维持。变化前捕获，交接过程安静且经验证；布局补偿本身永不写入快照，稳定后按既有交接，路由/代际/来源无效即 fail-closed。本地视口/焦点不是聊天权威也不是上下文锚点；既有标签页同类交互属同一交互类 | **Locked** |
| **VIEWPORT-15** | **流式阅读/跟随语义**。流式期间消息视口内的主指针按下（当前展示即选中、无程序化所有者、当前活跃助手待定/处理中/搜索中或块流式中）采用如实的可见消息行锚点（即使在物理底部）；只暂停跟随，原生点击动作与生成继续；同事件清除合成按压会话。触控/笔/右键/中键、消息视口外、非流式、非当前路由不适用。唯真实用户滚动到达物理底部、显式回到底部、显式发送可恢复跟随；被动增长与无会话滚动永不恢复；快照邻近不是物理底部。行锚 vs 底部跟随是含义区分，不新增持久化暂停模式；单写者接管与受守卫的稳定快照规则不变 | **Locked** |
| **VIEWPORT-16** | **位置意图优先级**。独占的路由/页面恢复与分隔线事务保持其所有权；真实导航与用户意图可按既有许可取代；普通控件与阅读意图优先于被动布局与跟随；跟随仅在活跃底部语义未被阅读/控件取代时被允许。显式导航/发送/回到底部与真实用户滚动取代陈旧本地保持；路由/代际/窗口/停用/删除守卫适用 | **Locked** |

> 决策锁 ID 是编排内部协调令牌的产物语义表达：VIEWPORT-* 是本文档的 durable 决策 ID，不进入代码注释、配置或提交信息。
>
> **生命周期与目标输入边界澄清（不新增决策锁）**：长存续的路由稳定视口会话（VIEWPORT-1）与可分离/重连的视口资源、与每次进入创建的短寿命激活/恢复事务（VIEWPORT-6/7/11）是三类不同存续期的对象：停用取消旧事务并断开资源，但保留合法稳定快照。目标输入边界不变：普通恢复意图的输入只来自目标自身（VIEWPORT-5），普通选中路由切换仍按自身快照/自身默认定位；分隔线显式延续意图是唯一例外输入（§6），它保持当前视口、不改变分支权限与上下文锚点。同路由在位交互（VIEWPORT-13/14）不产生恢复意图、不经过 §5 生命周期——它是同一路由内的几何保持，不是跨路由恢复；不得以它的存在论证普通切换可复用发出侧输入。
>
> **页面交互语义澄清**：主要页面往返（例如 Chat→Settings→Chat）是普通恢复意图的页面形态，不是新路由语义：返回同一聊天路由时从其上次稳定浏览位置继续（类浏览器标签行为）。每次页面重激活仍创建新的守卫事务（VIEWPORT-6/7/11），但允许保留投影优先（retained-projection-first）：先验证+对齐已有的有效保留投影，无需无条件取数或重建；保留投影不能安全覆盖所请求的稳定身份时，走既有的自身目标快照/默认恢复。保留投影的验证仅属展示正确性，不改变 loaded=complete/聊天新鲜度权威（PROJ 治理域不变），投影永不成为权威。

## 4. 状态与不变量（State and Invariants）

### 状态（State）

| 状态 | 归属 | 语义 |
|---|---|---|
| 路由本地稳定视口快照（按路由键） | Renderer 本地、随路由稳定视口会话长存续 | 每路由上次稳定视口；可丢弃、可重建（VIEWPORT-1）。页面停用与重连不销毁该会话；隐藏（`display:none`）期间不采样新快照 |
| 视口资源（可分离/重连） | 当前挂载作用域 | 已提交投影的挂载与度量占位；停用时断开、重激活时重连；断开不等于会话销毁，框架 effect 清理不得解释为永久销毁 retained 会话 |
| 选中路由 / 展示路由 | Renderer 本地 | 意图去向 vs 已提交渲染身份；切换期间两者可短暂不一致（VIEWPORT-2） |
| 恢复意图 + 恢复所有权（目标路由 + 代际） | 当前激活/恢复事务作用域 | 从提交存活到稳定完成或终态回退；超前即失效（VIEWPORT-8/9/11）。普通恢复意图与分隔线显式延续意图必须区分，后者优先（§6） |
| 生命周期阶段 | 当前激活/恢复事务作用域（按代际守卫） | `positioning` / `placed` / `searching` / `aligned` / `stable` / `terminal fallback`（VIEWPORT-7）。旧事务的迟到完成永不复用于新代际 |
| 同路由交互保持（行锚 vs 底部跟随含义） | Renderer 本地、当前路由作用域 | 在位控件与流式阅读期间的本地保持含义：行锚（保持某可见消息行的稳定视觉区）或底部跟随（保持底部语义）。它是含义区分，不新增持久化暂停模式，不经 StoreSync 持久化（VIEWPORT-13/14/15） |
| 合成按压会话（transient） | 当前按压事件作用域 | 一次指针按下派生的瞬时会话，随同事件清除，不存活、不持久化 |

### 不变量（Invariants）

- **I-1**：任一路由的快照只表达该路由的稳定视口；快照的路由键与写入来源（展示路由）一致（VIEWPORT-1/2）。
- **I-2**：程序化定位的中间帧永不成为快照；只有走完 §6 稳定完成判定的位置才是稳定视口（VIEWPORT-3）。
- **I-3**：身份不一致的位置写入不存在：旧展示内容永不以新路由身份落快照（VIEWPORT-4）。
- **I-4**：目标定位的输入只来自目标自身（自身快照或自身确定性默认）；发出侧滚动值永不是目标定位输入（VIEWPORT-5）。同路由交互保持与分隔线显式延续不是该输入的例外——前者根本不进入恢复输入，后者是唯一的显式跨路由例外。
- **I-5**：未揭示的过渡对外不可见；揭示只发生在目标路由与目标代际一致时；揭示失败对外可见（VIEWPORT-6）。
- **I-6**：`searching` 停靠不改变意图、所有权与快照；分页完成不等于稳定完成（VIEWPORT-8）。
- **I-7**：过期代际的任何完成（提交、揭示、释放）均无效；释放恰好一次（VIEWPORT-11）。
- **I-8**：在位交互的连续性锚定被点击/聚焦的稳定视觉交互区；原始滚动值与任意旧行顶永不是连续性目标；无有效结构对应即无连续性目标，失败 fail-closed（VIEWPORT-13）。
- **I-9**：布局补偿永不写入快照；快照只由安静后验证的稳定位置写入；变化前捕获、安静交接（VIEWPORT-14）。
- **I-10**：流式期间被动内容增长永不劫持行锚阅读位置；被动增长与无会话滚动永不恢复跟随；快照邻近永不等同物理底部（VIEWPORT-15）。
- **I-11**：普通控件激活永不是显式滚动导航；原生焦点永不暗中重定位；显式导航/发送/回到底部与真实用户滚动取代陈旧本地保持（VIEWPORT-13/16）。

## 5. 生命周期（Lifecycle）

阶段按序推进，不可跳级，不可回退到更早阶段冒充完成：

1. **`positioning`**：过渡已提交，目标投影隐藏但可测量，恢复意图已建立。等待有效首绘定位。
2. **`placed`**：首绘已按目标意图放置（程序化几何已生效）。此时**不是**稳定：对齐与安静尚未验证（VIEWPORT-7）。
3. **`searching`**（条件进入）：目标稳定身份尚未驻留/覆盖，需要恢复拥有的分页。允许边缘停靠以推进分页；停靠本身是中间几何（VIEWPORT-8）。
4. **`aligned`**：目标身份已驻留且被覆盖，分页已完成，布局已安静，但稳定提交尚未落快照。
5. **`stable`**：§6 合取条件满足，快照已提交，或等价的非分隔线目标完成判定满足；恢复意图清除，所有权释放（恰好一次）。
6. **`terminal fallback`**：稳定路径不可达（缺席且无合法回退、超前、删除/卸载、验证失败）。释放所有权并可见失败，不提交中间几何；保留已有的合法目标快照（VIEWPORT-10）。

分隔线目标在 `searching` 中可多次分页；意图与偏移在窗口增长中存活，不重置（VIEWPORT-9）。

**停用与重激活（VIEWPORT-10/11 的澄清，不新增语义）**：页面停用取消旧激活/恢复事务（旧事务的晚到完成一律无效）、断开视口资源、保留合法稳定快照；隐藏期间不采样新快照。重激活依据目标快照或目标默认（或显式分隔线意图）创建新守卫的定位过程，旧完成不复用新代际。框架 effect 清理只断开当前挂载资源，不可解释为永久销毁 retained 会话。

**保留投影优先的页面重激活**：页面重激活的新事务允许先验证+对齐已有的有效保留投影，无需无条件取数或重建；验证通过即可对齐为当前稳定视口。保留投影不能安全覆盖所请求的稳定身份（缺席、未覆盖、代际不一致）时，走既有的自身目标快照/默认恢复（含 §6 的分页与对齐路径）。保留投影的验证仅属展示正确性，不证明投影完备性或聊天新鲜度，投影永不成为权威。

**同路由在位交互不经过本节生命周期**：§7 的捕获→补偿→安静验证是同一路由内的几何保持过程，不创建恢复意图、不进入 `positioning/placed/searching/aligned/stable` 阶段、不释放恢复所有权。两者不得互相冒充完成信号。

## 6. 稳定完成判定（Stable Completion）

- **分隔线目标**（VIEWPORT-9，四者合取，缺一即未完成）：
  1. 所请求的稳定身份分隔线、或显式合法的共享消息回退已驻留且被覆盖（隐式就近替代不计）；
  2. 恢复拥有的分页已完成（无未完成的窗口扩展）；
  3. 目标已对齐（意图身份与实际展示身份一致）；
  4. 布局已安静（无未结算的布局变化）。
- **非分隔线目标**：目标身份驻留且被覆盖、已对齐、布局安静；有快照时按快照身份 + 行内偏移/底部语义，无快照时按确定性目标路由默认（VIEWPORT-5）。
- **分隔线显式延续意图（已实现特例，不改变分支权限与上下文锚点）**：从分支分隔线发起的切换携带显式意图，优先于目标历史快照——定位期间保持当前视口，不被目标历史快照覆盖；只有稳定后的结果才成为该路由后续会话位置。普通恢复意图与该显式意图必须区分，不得互相覆盖对方的输入边界。
- **驱动规则**：分页由状态/驻留驱动，永不由滚动事件驱动；滚动事件不得作为完成信号（VIEWPORT-9）。
- **禁止**：以 `placed` 首绘几何、以 `searching` 边缘停靠、以发出侧滚动值提交稳定快照（VIEWPORT-3/7/8）。
- **保留投影验证**：保留投影的验证+对齐只确认展示身份与目标稳定身份一致且已覆盖、对齐且布局安静；它不证明 loaded=complete，不证明聊天新鲜度，不替代窗口读取与权威成员判定（PROJ 治理域不变）。验证失败时按既有的自身目标快照/默认恢复，投影永不成为权威。
- **同路由与流式语义不经过本节完成判定**：§7 的在位连续性以“首见帧与每一可见帧连续 + 安静后验证”为完成，不落恢复快照语义；§8 的行锚/跟随含义切换不提交稳定完成、不清除恢复意图（恢复意图本就不存在于同路由）。

## 7. 同路由在位交互视觉连续性（Same-Route In-Place Continuity）

本节为 Authoritative（VIEWPORT-13/14，已验证的 durable 语义）。

- **权威原则**：以**视觉基线**为准**向变化方向平衡高度差**。视觉基线是符合心理预期的不变量，通常即交互区域本身；若交互区域被替换且几何本身变化，则取变化区域下方/上方未变化的结构边界，不人为压缩组件以维持错误点。保持对象仍为被点击/聚焦的稳定视觉交互区（行身份 + 区内位置语义），而不是原始滚动值、固定 `scrollTop` 数字或任意旧行顶。把视口钉在旧数值上而让交互区滑出可视帧，或跳到无关行顶，均违反本节。镜头稳定不等于固定 `scrollTop` 数字；自然变化的上方/下方内容按布局变化，不要求所有页面像素不变。
- **方向规则（语义示例）**：平衡方向由变化侧决定——变化在基线上方则向上平衡，变化在基线下方则向下平衡。模型标签上方回答变化向上平衡；分支分割线下方内容变化向下平衡；编辑消息以上方变化取下方不变边界为基线。此三者为方向规则的语义示例，不是当前分支实现已通过的声称，不改变分支权限与有效路由算法（BRANCH 治理域不变）。
- **共享机制而非按钮名**：仲裁机制按稳定消息/组作用域内的**任意区域身份**运作，不按按钮名称分派——同一保持器覆盖全部在位交互类；既有标签页同类交互经兼容别名调用同一所有者，适用本节而非另立语义。
- **结构对应继承（示例为契约应用说明，非穷举证明）**：若交互使原控件被替换（例如消息进入编辑态、操作区形态切换），由**结构对应的稳定交互区**继承连续性（例如消息底部操作区与编辑器操作区的对应、折叠消息组）。对应关系以结构语义判定，不以像素巧合判定。未逐一列举验证的控件类（含重发/重新生成等）仍受本通用规则约束，但本文档不为其虚构逐一证明（覆盖边界见 §12）。
- **无对应即失败**：已移除的区域若无有效结构对应，**fail-closed**——不猜测替代区、不谎报稳定成功、不以就近行冒充连续。要求消失的控件仍停留在指针下是不可能的要求，本文档不作此要求。
- **逐帧连续**：首见帧与每一个可见帧均须按同一视觉基线连续；仅终态位置正确而中间出现可见跳动/回跳，不能抵消首见错位。终态纠正不是连续性证据。
- **边界钳制与用户主动**：用户主动镜头移动优先；真实物理滚动边界钳制优先于保持——保持目标超出可滚动范围时诚实钳制到边界，不反向制造空白或错位。该钳制是真实物理不可达边界的如实处理，与高度最小/最大约束是不同语义。不可达处的被动增长不得替换阅读锚点，也不得据此认证稳定区域。
- **正常外观**：组件保留正常样式留白与按钮比例；视觉基线选择不靠强制尺寸一致维持，不为对齐而压缩组件。
- **完成形态**：变化前捕获共享稳定区域身份，预补偿观察效应/替换证明，安静后验证交接且不谎报成功；无效应变化直接丢弃且不写入快照；补偿本身仍不写快照，稳定后按既有交接；路由/代际/来源无效即 fail-closed；过期保持由守卫失效。
- **非导航性**：普通控件激活**不是**显式滚动导航；原生焦点行为不得暗中重定位（不得以焦点为名义行导航之实）。助手 Escape 行为不在本节验证范围：已验证的仅是 Escape 下视口保持开启且不位移，本文档不声称任何 Escape 取消语义已验证。
- **单一仲裁**：同一路由的全部在位交互与布局补偿由**共享的 renderer 本地控制器/保持器**唯一仲裁，不设按钮级补偿器，不允许每组件独立滚动或独立补偿。变化前捕获待变区的稳定身份，布局结算后安静交接并验证连续性；**布局补偿本身永不写入快照**——快照只由安静后验证的稳定位置写入。单写者接管与受守卫的稳定快照规则不变。
- **非权威性**：本地视口/焦点保持不是聊天权威，也不是上下文锚点；保持动作永不移动上下文锚点，锚点变化永不提交视口保持。

## 8. 流式阅读与跟随（Streaming Reading and Follow）

本节为 Authoritative（VIEWPORT-15，已验证的 durable 语义）。本文档不规定像素阈值、持续时长、选择器命名与调用链细节。

- **暂停条件（合取）**：流式期间消息视口内的主指针按下，且当前展示即选中、无程序化所有者、当前活跃助手待定/处理中/搜索中或块流式中时，采用如实的**可见消息行锚点**作为阅读位置——即使按下时视口正处物理底部。采用行锚是如实记录用户正在看哪一行，不是导航。
- **暂停范围**：只暂停跟随；原生点击动作与生成过程继续，不阻断、不取消。
- **瞬时会话**：同事件内存在合成按压会话用于去噪，**同事件清除**，不存活、不持久化、不跨事件复用。
- **不适用范围**：触控/笔、右键/中键、消息视口外区域、非流式状态、非当前路由，均不触发本节暂停。不得把本节推广为“任何键盘动作暂停”或“任何点击都暂停”的宽泛主张。
- **恢复条件（穷举）**：唯三者可恢复跟随——真实用户滚动到达**物理底部**；显式回到底部动作；显式发送动作。被动内容增长、无会话的滚动事件永不恢复跟随。快照邻近（`isAtBottom` vicinity 含义）永不等同物理底部；本文档不规定任何像素距离数值。
- **底部交接**：底部交互交接保持如实的行锚——即使快照邻近语义报告在底，交接仍以真实可见行锚为准，不作隐式跟随；唯真实物理底部滚动或显式底部/发送授予跟随。
- **含义区分而非模式持久化**：行锚 vs 底部跟随是视口含义的区分，不新增持久化暂停模式，不经 StoreSync 或任何持久化通道变成第二权威。
- **单写者与守卫**：行锚采用走单写者接管；程序化导航的所有权/时效守卫保持不变——过期程序化完成永不覆盖用户行锚。
- **控制优先流**：控制优先的流同样适用本节——暂停/恢复条件不变，原生复制等动作不受影响。

## 9. 位置意图优先级（Position Intent Priority）

本节为 Authoritative（VIEWPORT-16，已验证的 durable 语义）。

- **独占事务保持所有权**：进行中的路由/页面恢复事务与分隔线显式延续事务保持其所有权；在位交互的保持动作与被动布局变化不得篡夺其分页、提交与释放权。
- **真实导航与用户意图可取代**：显式导航、显式发送、显式回到底部与真实用户滚动可按既有许可取代陈旧本地保持（路由切换超前规则 VIEWPORT-11 仍适用；同路由内取代不经过超前释放，只更新本地保持含义）。
- **阅读与控件优先于被动**：普通控件交互意图与流式阅读意图优先于被动布局位移与跟随增长——被动增长永不劫持行锚阅读位置；跟随仅在活跃底部语义**未被**阅读/控件取代时被允许。
- **守卫适用**：路由/代际/窗口/停用/删除守卫对本节同样适用——过期代际的取代无效；停用期间不采样新保持；删除/卸载使保持失效。
- **分隔线延续仍是跨路由显式意图**：分隔线显式延续意图保持跨路由显式意图地位，其分页仍由状态/驻留拥有（不由滚动事件驱动），稳定提交规则不变（§6 四者合取）。

## 10. 可见性原子性（Visibility Atomicity）

- 目标投影从提交到有效首绘定位完成前保持**隐藏但可测量**（占位可度量，不向用户展示错位内容）（VIEWPORT-6）。页面重激活同样从重激活起守卫可见性：在无效几何可绘制之前即守卫，不只在目标替换后才守卫。
- 揭示条件：展示路由 == 目标路由，且代际 == 目标代际，且首绘定位已验证。任一不一致即不揭示。
- 首次可见即正确：有效的首次可见视口与无可见纠正行程属交互正确性，独立于终态正确性——终态位置正确不能抵消首次可见错位或可见回跳。异步/完整恢复与失败路径仍按既有语义：隐藏但可测量推进，失败 fail-visible；保留 §5/§6 允许的 searching/边缘停靠与恢复拥有的分页语义，不普遍要求最终稳定完成前不得揭示，也不禁止合法的可见分页。
- 同路由在位交互的可见性：交互的每一可见帧均须连续（§7）；不得以“终态正确”掩盖可见纠正行程。
- 失败路径 fail-visible：定位失败、超前失效、删除/卸载导致的终态回退必须使用可见的确定性 fallback（目标默认或保留的合法快照路径），永不静默停留在隐藏状态，也永不展示错位内容冒充成功（VIEWPORT-6/10）。

## 11. 持久化与权威边界（Persistence and Authority Boundary）

- 聊天权威持久化是 Main SQLite（Drizzle + better-sqlite3），经版本化迁移治理；本文档不改变其 schema、迁移流程与 L2 兼容导入语义，一律以 [SQLite migration governance](../archived/sqlite-migration.md) 为准。
- 路由本地稳定视口快照、选中/展示路由、恢复意图与所有权、生命周期阶段均为**一次性、可丢弃、可重建的 renderer 本地投影**；不得经 StoreSync 或任何持久化通道变成第二权威，不得写入 SQLite/Dexie 聊天权威（VIEWPORT-1；PROJ-2 仍然适用）。页面停用/重激活不产生新的持久化承诺，不承诺重启续读。保留投影（含其验证+对齐）同样仅属展示正确性，不证明 loaded=complete 或聊天新鲜度，投影永不成为权威。
- 同路由交互保持（行锚 vs 底部跟随含义）、合成按压会话、布局补偿中间量同样为 renderer 本地瞬时状态，不持久化、不跨路由复用、不进入聊天权威（VIEWPORT-13/14/15）。
- 上下文锚点与 `contextCount` 属普通 renderer 设置持久化，其有效性/默认/继承/闭包派生由 [Context window governance](./context-window.md) 治理；视口快照与上下文锚点是两种不同的状态——前者是“切回来时看哪里”（本规范），后者是“请求带哪段上下文”（CW-2/CW-6）。视口变化永不移动上下文锚点，锚点变化永不提交视口快照。
- 路由构成、分支锚点、变更权限由 [Topic Branches](./topic-branches.md) 治理；路由切换永不改变 topic 身份（BRANCH-2/11）。视口快照按路由键隔离，分支路由各持其快照，互不写入。
- 完备性能力（`window` / `answer-group` / `context-closure` / `whole-topic` / `naming-context` / `topic-activity` / renderer-only `loaded-projection`）由 [Projection Completeness](./projection-completeness-authority.md)（PROJ-3…PROJ-5）治理；视口定位只消费已加载投影与窗口读取结果，永不以视口位置推导权威成员、顺序或闭包范围。

## 12. 失败、超前与测试契约（Failure, Supersession, Test Contract）

### 失败与超前（VIEWPORT-10/11）

- 终态回退：释放恢复所有权（恰好一次），对外可见失败，不提交任何中间几何；已有的合法目标快照原样保留，供下次同路由进入使用。
- 超前（新切换在旧过渡完成前提交）、目标路由变更、topic/分支删除、组件卸载：旧过渡的恢复意图与所有权立即失效；旧所有者的迟到稳定提交、迟到揭示、重复释放一律丢弃。
- 释放恰好一次：稳定完成与终态回退是互斥终态；同一过渡不得既提交稳定又执行回退，不得释放两次。

### 回归契约（VIEWPORT-12，六组冻结，语义逐字保留）

以下六组为必需回归契约；实现位置与用例组织见架构文档，语义判定以本文档为准：

1. **无滚动顶部分隔线往返**：两路由均无用户滚动时反复切换，目标始终回到各自稳定视口，无漂移、无发出侧污染。
2. **普通用户滚动后无滚动往返**：一侧经普通用户滚动形成稳定视口后，无滚动切离再返回，恢复该侧用户视口而非发出侧位置。
3. **无快照目标默认**：从未形成快照的目标路由进入时落确定性目标路由默认，不采用发出侧滚动值。
4. **快速超前**：连续快速切换只承认最新代际；过期代际的迟到完成不揭示、不提交、不干扰最新过渡。
5. **分隔线缺席锚点分页与偏移**：所请求分隔线缺席时经恢复拥有的分页使回退身份驻留且被覆盖，意图与偏移在窗口增长中存活，最终稳定位置与偏移正确；无合法回退时走终态回退而非虚假提交。
6. **原子可见性与失败路径**：过渡期间不展示错位内容；失败时可见失败而非静默隐藏；不提交中间几何为快照。

### 补充回归覆盖（VIEWPORT-12 的子情形，不改变六组冻结计数）

- **A. 页面停用/激活后连续切换**：停用后重激活再连续切换，目标仍按自身快照或自身默认（或显式分隔线意图）定位；停用期间的隐藏几何永不成为快照，会话位置不丢失。
- **B. 旧事务迟到失效**：停用或超前取消旧事务后（含页面停用中断的旧恢复），旧事务的晚到稳定提交/揭示/释放一律丢弃，不得复用新代际，不得干扰最新过渡。
- **C. 分隔线特例不回归**：从分支分隔线发起的切换保持当前视口、不被目标历史快照覆盖；只有稳定后的结果成为该路由后续会话位置；该特例不改变分支权限与上下文锚点。
- **D. 页面往返首次可见与无漂移**：Chat→Settings→Chat 返回同一聊天路由时，首次可见即为该路由的稳定浏览位置，且无可见纠正行程（无可见回跳/二次纠正）；覆盖顶部/中部/底部的稳定位置、重复往返、快速返回。终态位置正确不抵消首次可见错位或可见纠正行程；异步/完整恢复的隐藏推进与允许的 searching/边缘停靠语义不变。

### 新增语义的自动回归覆盖（VIEWPORT-13…16，已验证；语义命名，无固件标识）

- **E. 在位交互逐帧连续与基线方向**：按正确视觉基线向变化方向平衡高度差并逐帧保持连续，自然变化的上方/下方内容按布局变化；组件保持正常样式留白与按钮比例，不以强制尺寸一致为前提。通用规则覆盖全部在位交互类；重发/重新生成等未逐一列举的控件类与分支分割线方向示例受同一通用规则约束，但本文档不为其虚构逐一证明——其回归状态以未来验证报告为准，不缩小通用规则，不构成实现已完成的声称。
- **F. 流式阅读/跟随**：流式主按压行锚暂停且仅暂停跟随、控制优先流同语义、真实物理底部滚动恢复跟随、显式回到底部/发送恢复跟随、被动增长与无会话滚动永不恢复、快照邻近不等同物理底部、底部交接以真实行锚为准。不得主张键盘暂停或自动恢复已受支持。
- **G. 位置意图优先级**：独占恢复/分隔线事务所有权不被在位保持篡夺；显式导航/发送/回到底部与真实用户滚动取代陈旧保持；阅读与控件意图优先于被动布局与跟随。

关闭证据为冻结生产构建上的规范六组 FULL 回归与上述新增语义的合同级 E2E FULL 及聚焦组件套件，均为原始 exit 0（证据归验证报告，本文档不复列卷宗、不记工作日志）。

### 证据层级

- 按 `AGENTS.md`「Testing and UI/E2E Evidence」路由；UI 变更的渲染/交互验证经 `ui-verify-change`。跨路由切换、分页/驻留、显隐原子性的合同级回归以 Playwright E2E 为准；隔离的定位纯逻辑以 Vitest/组件测试为先。诊断性观察（`pnpm ui:observe`、截图、dev-mode 运行）永不作为回归证据。
